# topicosllm

Default Flutter counter app. No custom dependencies beyond `cupertino_icons`.

## Commands

| Action | Command |
|--------|---------|
| Install deps | `flutter pub get` (not `dart pub get`) |
| Run app | `flutter run` |
| Run all tests | `flutter test` |
| Run single test | `flutter test test/widget_test.dart` |
| Lint + analyze | `flutter analyze` |
| Build | `flutter build apk` / `flutter build ios` / `flutter build web` |

Hot reload: `r` in terminal (or save). Hot restart: `R`.

## Code style

- Lint rules: `package:flutter_lints/flutter.yaml` (standard Flutter recommended set)
- No codegen, no build_runner, no migration tooling
